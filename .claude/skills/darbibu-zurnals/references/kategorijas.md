# Atslēgu vārdnīca

Konsekventa atslēga ir viss. Vienmēr izvēlies no šī saraksta; jaunu pievieno tikai tad,
ja neviena neder — un tad pieraksti to šeit.

## Technitis — pārdošana

| Atslēga | Ietver |
|---------|--------|
| `komercpiedavajums` | Piedāvājumu sagatavošana Word/WhatsApp, cenu likšana |
| `pn-akts` | Pieņemšanas/nodošanas akti |
| `ligums` | Pirkuma, servisa, nomas līgumi |
| `klientu-zvani` | Izejošie zvani klientiem, atgādinājumi |
| `klientu-epasti` | Atbildes uz pieprasījumiem, sarakste |
| `piedavajumu-follow-up` | Sekošana neatbildētiem piedāvājumiem |
| `cenu-meklesana` | Cenu, pieejamības, piegādes termiņu noskaidrošana pie piegādātājiem |
| `klienta-parbaude` | Lursoft, maksātspējas pārbaude |
| `crm-uzturesana` | Datu ievade, pipeline atjaunošana |
| `nedelas-reports` | Iknedēļas atskaite vadībai |

## Technitis — saturs

| Atslēga | Ietver |
|---------|--------|
| `web-apraksts` | OpenCart preču apraksti |
| `sludinajums` | ss.com un citi sludinājumi |
| `speca-datu-ievakšana` | Specifikāciju izvilkšana no PDF katalogiem |
| `foto-apstrade` | Bilžu sagatavošana veikalam |

## Technitis — operatīvi

| Atslēga | Ietver |
|---------|--------|
| `noliktava` | Krājumu pārbaude, rezervācijas |
| `piegades-koordinacija` | Logistika, termiņi |
| `servisa-koordinacija` | Remontu, garantiju kārtošana |
| `iekseja-sapulce` | Sapulces, saskaņošana ar kolēģiem |
| `dokumentu-mekleana` | Faila vai vecas sarakstes meklēšana |

## Mācības un attīstība

| Atslēga | Ietver |
|---------|--------|
| `ai-eksperimenti` | Skillu būve, promtu testēšana |
| `macibas` | Kursi, lasīšana, video |
| `biznesa-planosana` | Projektu reģistrs, idejas |

## Privāti

| Atslēga | Ietver |
|---------|--------|
| `gimenes-logistika` | Bērnudārzs, plānošana |
| `majas-lietas` | Rēķini, remonti, iepirkšanās |

---

**Jaunas atslēgas noteikumi:** mazie burti, bez garumzīmēm, ar defisēm, maks. 3 vārdi,
apraksta DARBĪBU, nevis klientu vai preci (`komercpiedavajums`, nevis `bomag-piedavajums`).
